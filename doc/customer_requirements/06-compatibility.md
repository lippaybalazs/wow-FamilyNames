# Compatibility

- **COMPAT-001** Compatibility with the default Blizzard chat UI and guild roster shall be prioritized.
- **COMPAT-002** Compatibility with other chat and UI addons shall be pursued on a best-effort basis; no specific third-party addon is a required compatibility target.
- **COMPAT-003** Original WoW functionality shall remain intact, including targeting, whispering, inviting, context menus, and inspection.
- **COMPAT-004** Commands such as `/target CharacterName` shall continue to work with the original character name.
- **COMPAT-005** The supported WoW client version shall be 7.3.5.
- **COMPAT-006** Cross-realm behavior is outside the required scope.
