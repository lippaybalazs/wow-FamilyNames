# Persistence and Storage

- **STORE-001** Family names received from other characters shall be stored in memory only.
- **STORE-002** Received family names shall not persist between game sessions.
- **STORE-003** An offline character's family name shall not be used or displayed, except in that character's logout notification using the value known immediately before logout.
- **STORE-004** No fixed storage capacity, eviction policy, or time-based expiration is required.
- **STORE-005** Empty family names shall be retained in memory as valid known values.
